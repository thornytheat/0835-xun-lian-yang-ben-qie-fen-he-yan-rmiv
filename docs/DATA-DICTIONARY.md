# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 record, duplicate, rule。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `sample`、`entity`、`fingerprint`、`day`、`split_code` 排列。最终值单位见阶段结果。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

实体键、完全一致的指纹和已确认近重复关系都形成传递分组。日期早于截止日归训练集，等于截止日归评估集。跨日期组或固定集合与时间边界冲突时整组隔离，保留证据。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。
